## Архитектурный контракт (после 0.2)
- Логика (`config`, `geometry`, `entities`, `world`, `physics`, `camera`, `mechanics/*`, `ai`) **не импортирует pygame** — тестируется pytest без окна.
- `World.update(controls)` — единая точка шага симуляции; `Control(target, speed_factor, split, eject)` одинаков для человека и бота.
- Весь pygame — в `render.py` и `game.py`.
- Headless-проверка: `SDL_VIDEODRIVER=dummy python3 agar.py --frames 600`.

## Процесс
- Каждый PR тимлид проверяет: diff, `python3 -m pytest`, headless-прогон игры, сценарные симуляции. После проверки — комментарий «✅ проверено менеджером», затем PR ждёт владельца.
- Стек PR: следующая ветка строится от предыдущей; конфликты разрешаются **merge-коммитом** (без rebase и force-push).
- Codex-помощники не выполняют git (песочница требует повышенных прав) — пишут код, коммит/push/PR делает тимлид после ревью.
